# SPARC Illinois Tech Website Prototype

Responsive static website built with HTML, CSS, JavaScript, and local SVG graphics using Illinois Tech-inspired red, black, white, and gray styling.

## Public-facing pages
- index.html — Home
- about.html — About SPARC
- scholarship.html — Scholarship and eligibility
- programs.html — Undergraduate programs
- mentoring.html — Mentoring model
- activities.html — Activities and events
- scholars.html — Public-facing placeholder; no mentee names/photos shown
- team.html — Four confirmed PIs and JPM
- news.html — NSF grant news
- faq.html — Frequently asked questions
- contact.html — Contact information

## Internal page
- mentor-matching.html — Internal roster of 12 mentees and mentor assignments. Not linked in public navigation; do not publish unless approved.

## Assets
- assets/style.css — Shared responsive styling
- assets/script.js — Mobile navigation
- images/illinois-tech-lockup.svg — Local typographic fallback lockup, not official logo artwork
- images/hero-abstract.svg — Original decorative hero illustration
- images/pi-*.svg — Initials placeholders for PI headshots, not real photos

## Preview
Extract the ZIP and open `index.html` in a browser. No build step is required.

## Before launch
1. Confirm current scholarship amounts, eligibility, program list, renewal conditions, and deadlines with SPARC.
2. Replace the typographic lockup with an approved official logo, if authorized. Official resources: https://www.iit.edu/marketing-communications/resources/logos
3. Replace PI initials placeholders only with approved photos.
4. Get written approval for biographies, emails, photos, quotes, and any scholar details.
5. Keep the repository private until program owners approve publication and hosting settings.
6. Review all page copy and links before public launch.
