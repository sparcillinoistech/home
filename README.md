# SPARC Scholarship Program Website

Static website for the Illinois Institute of Technology SPARC Scholarship Program.

## Pages
- `index.html` — Homepage, scholarship information, eligible programs, and the FAQ section.
- `mentoring.html` — Mentoring model and digital hub information.
- `team.html` — Principal Investigators, faculty mentors, and project management.
- `scholars.html` — Single combined scholar roster.
- `activities-news.html` — Dated program news and October 27, 2026 event photographs.

## Navigation
Home | Mentoring | Team | Scholars | Activities & News

The FAQ is retained on the homepage. There is no separate FAQ page. Scholars is a top-level navigation item.

## October 27, 2026 photographs
Three image placeholders are located in `images/events/` as `mentor-mentee-lunch-1.png` through `mentor-mentee-lunch-3.png`. Replace these files with approved event photographs using the same filenames.

## Publishing
Upload the contents of this folder to the private GitHub repository. Check all links and confirm that photographs are approved for public display before making the repository public.
